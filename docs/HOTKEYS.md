# Hotkeys

These are the defaults. They work in the game, even with the app in the background, and you can change every one under **Settings → Hotkeys** (press Rebind, then the new keys). Changes apply at once and are saved.

| Key | What it does |
|---|---|
| **F8** | Start or stop fishing |
| **F10** | Pause or resume |
| **F4** | Calibrate again now, saved as a new profile |
| **F12** | Quit |
| **Numpad 2** | Quick fix: set the cast position |
| **F9** | Quick fix: redraw the reeling bar |
| **F6** | Quick fix: redraw the SHAKE button |
| **F11** | Quick fix: set the catch message area |
| **F3** | Write a SHAKE diagnostic report (only while the game is in front) |

**Quick fixes** change one piece of your calibration. They are switched off every time the app starts, so a stray key press can't change anything: turn them on in the Calibration page when you need one. Press the key in the game and a still of it appears for you to draw on. A fix drawn wrong can upset fishing, so when in doubt run the full calibration instead.

There is one more setting that is not a hotkey of the app but the game's: the **rod hotbar key**, the key Roblox uses to take out your rod. You set it in the calibration, and it can be changed under Settings → Hotkeys.
