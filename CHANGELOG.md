# Changelog

## 0.1.0 - 2026-10-02

First public release.

- Fishes by itself: casts, waits for a bite, clicks SHAKE, plays the reeling bar and recasts.
- Reads each catch: fish, mutations, rarity and value.
- Live dashboard and an Inventory of past sessions with charts, a searchable log and CSV export.
- Skip rarities: let chosen rarities go instead of reeling them in.
- Guided calibration with a picture for every step, up to five saved profiles, and quick fixes for a single piece.
- "Draw it myself" for the SHAKE button and the reeling bar when the automatic detection misses.
- Light and dark themes, an accent colour, a dyslexia-friendly font option and optional sounds.
- Licence, privacy notice and third-party notices read and accepted on the first start.
- Safe by default: input is only sent while Roblox is the window in front, the diagnostic report captures the game window only, and the app makes no network connections of its own.
